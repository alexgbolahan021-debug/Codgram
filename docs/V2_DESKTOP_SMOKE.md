# Codgram V2 Desktop Smoke-Test Record

The Electron shell was launched under a virtual display on 2026-08-22. The Codgram desktop window rendered with the **Native desktop** status and the **Choose folder directly** control. Activating the control opened the operating-system project-folder picker titled **Choose a Codgram project folder**. A visible temporary project named `CodgramDesktopSmoke` was selected in that picker.

The desktop lifecycle was then exercised through the same selected-project state and local-server restart path in an automated Electron smoke mode. The restarted local server received `CODGRAM_WORKSPACE_ROOT=/home/ubuntu` and `CODGRAM_WORKSPACE_ID=CodgramDesktopSmoke`; the rendered Electron dashboard displayed `CodgramDesktopSmoke` in both the selected-workspace header and project control. The true native-picker confirmation was subsequently re-run after the renderer-refresh repair and produced the same locked server environment and visible selected-project result. A test-only renderer assertion also reported `selected workspace visible: CodgramDesktopSmoke` after React hydrated the reloaded desktop page. This verifies the bounded workspace handoff, renderer state, and visible desktop result.
